# IFmont Servis Android APK

Android APK verzija IFmont Servis aplikacije.

- Paket: `hr.ifmont.servis`
- Verzija: `10.3-apk`
- Minimalni Android: 10 (API 29)
- Lokalni podaci ostaju spremljeni u aplikaciji
- Slike se mogu odabrati s mobitela/tableta
- PDF i backup datoteke spremaju se u `Downloads/IFmont`
- Google Drive gumb otvara Android izbornik za dijeljenje; odaberi Google Drive

GitHub Actions automatski gradi debug APK nakon push-a na `main`.
Artefakt se zove **IFmont-Servis-APK**.
